# Synapse v2.1.19: "the scheme nginx overwrote"

Patch release completing 2.1.18. No schema migrations, no new endpoints, no new
configuration keys. Only the frontend image changes.

## Fixed

### The frontend nginx replaced the edge's `X-Forwarded-Proto` with its own `$scheme` [F17]

2.1.18 taught the backend to build the MCP OAuth issuer from `X-Forwarded-Proto`. In the
TrueNAS deployment the Cloudflare Tunnel reaches the frontend nginx over plain http, and
`nginx.conf.template` set `proxy_set_header X-Forwarded-Proto $scheme`, so the backend
received `http` and both `.well-known` endpoints still advertised `http://`.

nginx now forwards the incoming `X-Forwarded-Proto` when present and falls back to
`$scheme` for direct connections (a `map` to `$synapse_forwarded_proto`, applied to all
three proxied locations). Verified against `nginx:alpine` with the shipped template: with
`X-Forwarded-Proto: https` the backend receives `https`, without it `http`.
