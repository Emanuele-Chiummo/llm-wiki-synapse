# Synapse v2.1.22: "one color per area"

Patch release adding a third color mode to the knowledge graph, so a vault organised by
domain vocabulary (ADR-0054, F18) can be read by thematic area at a glance. No schema
migrations, no new endpoints, no new configuration keys.

## Added

### Color the graph by domain [F4][F18]

The graph header has a third toggle next to "Type" and "Community": **Domain**. In this mode:

- every node takes one stable color per vocabulary domain (`colorForDomain(node.domain)`,
  same name → same color across sessions), untagged nodes stay neutral gray;
- the legend lists one row per domain, sorted by node count, with an "Untagged" bucket last
  (`computeDomainLegendRows`, pure and memoised);
- a centroid label marks each area on the canvas (`computeDomainCentroids`, already in the
  code base, now wired to a `CentroidOverlay` with `testId="domain-overlay"`).

The domain is always the server's (`GraphNode.domain`, derived from `domain/<Name>` tags in
vocabulary order); the client never assigns or computes it (I2). "Community" keeps its
Louvain rows and the click-to-drill-down panel unchanged.

Why a third toggle instead of reusing "Community": the July change that colored the
community toggle by domain was undone by the GraphViewer extraction, and the community
toggle has since grown its own features (drill-down panel, cohesion markers). Keeping both
avoids losing either.

### Rebuild pages, links and vectors from `wiki/` after a database loss [ops]

`scripts/reindex_wiki_from_vault.py` (merged earlier on main, first released here) rebuilds
`pages`, `links` and the Qdrant vectors from the `wiki/` files with no LLM call and no vault
write. Restore path A in `docs/DEPLOY.md` uses it instead of relying on the watcher.

## Fixed

### `GraphNode.domain` was dropped before reaching sigma [F4]

`buildGraphologyGraph` copied `community` into the graphology attributes but not `domain`, a
leftover of the 1.9.3 W2 extraction. Every consumer reading `nodeDomain` from the sigma
graph saw `null`. The field is now passed through verbatim, covered by
`src/tests/graphDomainMode.test.ts`.

## How to verify after deploy

1. Settings > Advanced > `domain_vocabulary` must list the domains (the NAS vault has ten).
2. Open the graph, press **Domain**: nodes change color per area, the legend lists the
   domains with counts, and each area has a label on the canvas.
